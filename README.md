# 概要
このリポジトリは私が初めて制作したゲーム **「Extinguishing Contract」** のUnityプロジェクトとなります。  
ゲーム自体の情報に関しては、下記の情報一覧をご覧ください。

# 全体構造
本作では主に **「シーン間の完全な疎結合」** を達成することが設計における目標となりました。  
そのため本作の構造は、以下の思想を基に構築されています。  
**「一つの大きなデータベースに集約された情報を、各シーンが自由に閲覧して解釈する」**  
**「各シーンは自身の担当範囲に自分の解釈で情報を書き込む。」**  
**「情報ごとに解釈を設計時に統一する」**  
これによりシーン間の通信が消滅したため、シーンごとにロジックを制作することが可能となりました。  
また、ダミーのデータを用いたテストや、シーン単体での動作確認がスムーズに行えるようになり、開発効率の向上に大きく寄与しました。
